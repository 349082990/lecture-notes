# Interview Notes

A notes app for Windows with two modes:

- **Editor**: a Google Docs–style editor with real pages, headings, bullets, checklists, tables, images, find & replace, and export to Word / PDF. Paste from Google Docs or Word and the formatting comes along.
- **Immersive overlay**: a small, frameless reader that floats on top of other apps and shows your notes 1, 2 or a few lines at a time. Scroll it, jump between headings, or hide it with one shortcut, without switching away from what you're doing.

## Download

**[Download the latest version](https://github.com/349082990/interview-notes/releases/latest)**: under *Assets*, click `Interview-Notes-Setup-<version>.exe`.

Windows 10 or 11, 64-bit.

## Install

1. Run `Interview-Notes-Setup-<version>.exe`. It installs for your Windows account only (no administrator rights needed), adds Desktop and Start Menu shortcuts, and opens the app.
2. Windows may show **"Windows protected your PC"** because the app isn't code-signed. Click **More info → Run anyway**.

## Updates

The app checks for a new version each time you open it. When one is available, it asks you each time you open the app whether to **Update now** or **Not now**. Nothing is installed unless you say so. If you update, you'll see an "Updating Interview Notes" window and the app reopens by itself a few seconds later.

You can also check from **Settings → Updates** or **Tools → Check for updates**.

## Getting started

| Shortcut | What it does |
|---|---|
| **Ctrl + ]** | Show / hide the app, from any app |
| **Ctrl + Alt + I** | Switch between the editor and the overlay |
| **Ctrl + Alt + ↑ / ↓** or **Ctrl + Alt + scroll** | Previous / next heading |
| **Alt + scroll** (over any app) or **Alt + ↑ / ↓** | Scroll the overlay |
| **Ctrl + Alt + M** | Overlay: 1 line → 2 lines → custom → up to 25 |
| **Ctrl + Alt + O** | Overlay opacity |
| **Ctrl + Alt + 0** | Move the overlay back to the top of the screen |
| **Ctrl + Alt + Home / End** | Overlay: back to the start / go to the end |
| **Ctrl + Alt + = / −** | Overlay text size |
| **@** then **Tab** | Insert a page break, table, date, list… (type @page, press Tab) |
| **Tab / Shift + Tab** | Indent / outdent a bullet |
| **Ctrl + Q** | Quit |

The overlay and from-any-app shortcuts can be changed in **Settings → Keyboard shortcuts** (the sliders icon at the top right). Standard editing keys (Ctrl + Z, Ctrl + B, Ctrl + P, …) work as usual.

## Your notes stay on your PC

- Documents are saved as ordinary `.html` files in `Documents\Interview Notes` (you can change the folder in Settings). There's no account and nothing is uploaded.
- The only time the app goes online is to check GitHub for updates, and to copy in images when you paste from a web page or Google Docs.

## Uninstall

Windows **Settings → Apps → Installed apps → Interview Notes → Uninstall**. Your documents are kept.
